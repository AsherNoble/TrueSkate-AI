# M1-DIE5-20260925 — Five-touch die calibration pilot

Status: bounded XR2 probe completed; twelve markers detected and visually
checked. This is not yet the canonical calibration method and admitted no
training samples.

## Design

Five simultaneous 80 ms holds formed a die-five pattern around the usual
centre `(207, 448)` in XR logical points. The other positions were `(172, 413)`,
`(242, 413)`, `(172, 483)`, and `(242, 483)`. Each corner is `sqrt(35²+35²)` =
49.5 points from centre. All five positions pass the control-hitbox check. The
payload test confirms five distinct W3C pointer sources with pointer-down on
the same action tick.

Three isolated XR2 recordings contained four markers each. The reset tap was
before recording. Each recording was shorter than 12 seconds and remained in
gameplay. The last operator-confirmed park was SLS 2015 Los Angeles; each
recording has pre/post screenshots for provenance. Collection remained off.

## Result

The unchanged production centre/ring tap-onset detector ran independently at
all five known positions. An exploratory consensus required at least three
positions to detect an onset within one recorded frame. It found all twelve
markers with **5/5 positions on the same frame** each time. The existing
single-centre detector also found all twelve in this stationary scene. Crops
of the preceding, detected, and following frames were visually checked for
all twelve markers; the first visible marks occur at the detected frame.

The visible marks were 2.039–2.115 s after the *host call began*. That is not
WDA's internal submission-to-pixel latency; it includes the Appium/WDA path
and the recorder's time anchor. A first analysis mistakenly searched before
the next host call and consequently assigned each visible marker to the next
command. Chronological detection across the full recording resolved this:
four visible clusters matched four commands in each recording. This is a
warning against treating host call starts as pixel times.

Twelve successes in one stationary scene establish that this pattern can be
executed and detected on XR2. They do not show a gain over centre-only
detection, a false-positive rate in moving scenery, performance in other
parks/on XR1, or a repair for the two-anchor timing anomalies. Further testing
should compare the five-point consensus with human labels under those harder
conditions before changing the collector or aligner.
