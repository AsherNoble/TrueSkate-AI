# M1-LRDECAY-20260928 — Cosine learning-rate decay at 64×144

Status: approved by the operator (2026-09-28, with M1-SCALE-SUBSETS; $20
ceiling for both). The decision rule is fixed before launch.

## Question

The trainer holds lr at a constant 1e-3. Validation swings 2–5 pp between
adjacent epochs, and about half of each seed's failures are seed-specific
([M1-DIAG](M1-DIAG-20260928.md)). Does decaying the lr give a better
end-of-training model?

## Design

- **Change:** `--lr-schedule cosine`. Epoch *e* of 40 uses
  lr = 1e-3 × ½(1 + cos(π(e − 1)/40)), set at the start of each epoch. This
  is a pure function of the epoch index, so resume needs no state and no RNG
  is consumed. It is recorded in the resume config, the payload, and each
  epoch's history.
- **Held fixed:** everything else matches the
  [M1-HALFRES](M1-HALFRES-20260928.md) runs: 64×144, good13100 shards, seeds
  0–2, 40 epochs, batch 8, 16 base channels, temporal mixer, sequential
  decode, frame cache, L4.
- **Labels:** `good13100_halfres_cosine_seed{0,1,2}`, run with
  `--max-hours 3`.
- **Test partition untouched.**

## Decision rule

- **Reference:** constant lr at 64×144, three-seed mean of last-10 validation
  means **87.11%**.
- **Adopt cosine** if the cosine three-seed mean is **≥ 88.11%** (+1 pp).
- **Also reported:** best epoch and value per seed, last-10 standard
  deviation (stability), and the end component.
- **Known bias:** the last 10 cosine epochs run at low lr, which favours
  their mean. That is intended: it measures the end-of-training model we
  would use.

## Cost

~1.6 h per seed ≈ **$6.3** for three (cap 3 × 3 h).

## Result (2026-09-28) — adopt cosine

Code `7a0a7d1`, L4, 64×144. All three checkpoints record
`lr_schedule=cosine`. ~140–150 s per epoch, ≈ 1.6 h per seed.

| Seed | Constant: last-10 mean (SD) | **Cosine: last-10 mean (SD)** | Cosine best (epoch) |
|---|---|---|---|
| 0 | 86.99% (1.10) | **89.66% (0.32)** | 89.92% (40) |
| 1 | 85.15% (1.86) | **87.99% (0.13)** | 88.19% (35) |
| 2 | 89.18% (1.53) | **89.86% (0.15)** | 90.08% (32) |
| **Mean** | **87.11%** | **89.17%** (+2.06 pp) | |

- **Rule:** the threshold was ≥ 88.11%, and the cosine mean is 89.17%, so
  **cosine is adopted** for 64×144 development and for the M1-SCALE-SUBSETS
  rungs. Its three runs are the full 9,170 rung.
- **Stability:** the last-10 SD falls 5–12× (1.1–1.9 → 0.1–0.3 pp). The
  final epoch is effectively the model, so epoch selection no longer matters.
- **Best single epoch** is similar to constant (constant seed 2 peaked at
  90.94% on one noisy epoch). The gain is a higher, reliable plateau, not a
  higher peak.
- **Test partition untouched.**
