# M1-EXPAND-20260929 — Double the training set, weighted to hard parks, plus three new parks

Status: operator-approved design (2026-09-29). Collection runs in legs; each
park change is confirmed on the phone by the operator.

## Why

[M1-SCALE-SUBSETS](M1-SCALE-SUBSETS-20260928.md): validation error fell 39.7%
for the last doubling, so the model is still data-limited. Los Angeles
(21.4%) and Kansas City (16.3%) remain the worst parks. The operator chose to
over-weight them and add three unseen parks for diversity.

## Training (operator-approved 2026-10-01, $12.50; rules fixed before launch)

- **Data:** experiment `model1_expand_20260930` (train 18,394; validation and
  test unchanged), shards `sha256:85e6a844…` (22,324 samples, 46 shards) in
  volume subdir `model1_expand_20260930/`.
- **Recipe:** the current development default, unchanged: 64×144, cosine lr,
  temporal mixer, 40 epochs, batch 8, lr 1e-3, 16 base channels, sequential
  decode, frame cache (bytes budget, `e0424f9`), L4, seeds 0–2,
  `--no-evaluate-test`, `--max-hours 4`. The M1-ENDPROBE narrow end window is
  **not** included, so data is the only change.
- **Labels:** `expand20260930_cosine_seed{0,1,2}`.
- **Primary metric:** the three-seed mean of each seed's last-10-epoch
  validation recovery, against **89.17%** (the same recipe on 9,170 clips).
- **Rule:**

  | Three-seed last-10 mean | Reading |
  |---|---|
  | ≥ 91.33% (validation error ≥ 20% lower) | Still data-limited; scaling continues |
  | 90.17–91.33% | Helps, but flattening |
  | < 90.17% | No material gain from this data |

  Validation stays the selection partition. The test partition and the
  new-park holdout are not scored by this step; each needs its own decision.
- **Reported:** per-park validation failure rates (validation autopsy of each
  rung's best checkpoint), and the seed spread.
- **Caveat:** the added data changes volume, park weighting and park diversity
  together, so a gain is attributed to the combined intervention.
- **Cost:** expected ≈ $12.5–13.5 (≈ 250 s per epoch plus a ~25 min first
  epoch, ≈ 3.2 h per seed on L4). The caps allow up to $15.8.
