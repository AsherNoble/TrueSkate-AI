# M1-DIE5-R100-20260925 — Five-touch repeat with a 100 pt radius

Status: preregistered before any recording. Operator-requested repeat of
[M1-DIE5-COMPARE-20260925](M1-DIE5-COMPARE-20260925.md). No collection, corpus
edits or training are authorized by this record.

## Question

Does spreading the die-five corners from 49.5 pt to ~100 pt from the centre
change detector B's rejections or errors, and detector A's centre result?
The main interest is B's no-result rate on mid markers after a swipe, where
the 49.5 pt upper corners fired early on scenery (18–20% rejected).

## The only change

Corners move from ±35 pt to **±71 pt** per axis (centre-to-corner 100.4 pt):
`(207,448)`, `(136,377)`, `(278,377)`, `(136,519)`, `(278,519)`. No point
touches a protected control region (`point_is_safe`). The offset is a
collector flag, `--die-five-offset-pt 71`, stored per segment as
`die_five_offset_pt`, and read by the analysis script. The default (35) is
unchanged.

Everything else is identical to M1-DIE5-COMPARE as amended:
- **Detectors:** A unchanged; B frozen (≥4/5 within ±1 of a shared candidate,
  lower median, unchanged per-point defaults).
- **Phase 1:** the same probe (`--hold-s 0.05 --recordings 2`), one per XR
  (`--offset-pt 71`). Failure stops the study.
- **Phase 2:** the same launch scripts (production basic-linear loop, one-minute
  segments, 4 mid markers alternating die-five and single, aligner never
  spawned) with `--die-five-offset-pt 71`: **20 XR1 + 10 XR2 Los Angeles**,
  seeds 2509260001–20 and 2509261001–10. This matches the recordings actually
  scored in the original, so there is no gate or extension.
- **Phase 3:** the same blind viewer builder (±90 pt crops, which still
  contain the corners), same labelling rules, new seed. The same frozen
  scorers: `score_die_five_compare.py` and `score_multianchor_against_labels.py`.

## Comparison with the 49.5 pt run (descriptive)

Report side by side with the original scores:

- B no-result on starts, ends and die-five mids;
- B gross errors on accepted markers;
- A gross errors on Los Angeles starts;
- false alarms per second;
- corner check;
- B fit replay.

The two runs are on different days and in different fault states, so
differences are descriptive, not a controlled test. The mid-marker no-result
rate is the most informative number, because swipes are the same in both runs
and that rate does not depend on the reset fault reproducing.

## Scope

A pass does not change production calibration. Adopting either geometry
needs a later test, such as five-touch markers inside the multi-anchor fit.
