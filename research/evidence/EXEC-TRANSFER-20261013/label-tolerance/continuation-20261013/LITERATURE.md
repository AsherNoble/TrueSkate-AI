# Primary-source research, checked 2026-10-13

These papers address different noise mechanisms. No reviewed source establishes a transferable millisecond tolerance for True Skate command labels. Reported control rates, inference delays and corrupted-example fractions must not be converted into that tolerance.

| Primary source | Relevant evidence | Transfer limit |
|---|---|---|
| [Baker et al., VPT, NeurIPS 2022](https://cdn.openai.com/vpt/Paper.pdf), Appendix B.1, D.1, D.3, §4.6 | Custom game recorder records frame buffer/actions at each game tick. IDM takes128 frames, uses a five-frame noncausal convolution then unmasked transformers. Pseudolabelling uses128-frame windows with stride64 and keeps centre64 predictions. §4.6 tests downstream BC against IDM quality. | Native20Hz means50ms per step; it is **not** a reported±50ms label-misalignment allowance. No jitter sweep or millisecond threshold was found. Tick-synchronized human actions also avoid the particular synthetic-executor→human action-semantic mismatch here. |
| [Schmidt & Jiang, LAPO, ICLR 2024](https://arxiv.org/pdf/2312.10812), §4.3, §6.2, §6.4 | Learns latent actions from observed transitions; a small labelled action decoder grounds them. Latents can depend on state. §6.4 explicitly warns that delayed effects produce equally delayed inferred actions; it recommends extending past/future context. | Latent effects are not guaranteed physical controls or executor-independent human touches. No millisecond tolerance reported. |
| [Bruce et al., Genie, 2024](https://arxiv.org/abs/2402.15391) | Learns controllable latent actions from unlabelled videos without ground-truth controls. | This demonstrates an effect-based control interface; it does not validate recovery of original touch timing or supply an action-label noise threshold. |
| [Swamy et al., Causal Imitation Learning under Temporally Correlated Noise, ICML 2022](https://proceedings.mlr.press/v162/swamy22a/swamy22a.pdf), §1, §6 | Persistent action disturbances can create spurious observation/action correlations; ordinary BC need not consistently recover the expert policy. Instrumental-variable methods address this under their assumptions. | Action disturbance/confounding is different from independent timestamp error. Noise amplitudes/persistence are benchmark-specific; no universal ms threshold. |
| [Laskey et al., DART, CoRL 2017](https://proceedings.mlr.press/v78/laskey17a.html) | Adds calibrated execution disturbances while a supervisor supplies corrective demonstrations, improving recovery-state coverage. | This is not evidence that randomly shifting labels on fixed videos is harmless. Useful disturbance augmentation and corrupt supervision are distinct. |
| [Liu et al., Robust Imitation Learning from Corrupted Demonstrations, 2022](https://arxiv.org/pdf/2201.12594), Fig.1 and §2 | A median-of-means objective handles a constant fraction of arbitrary outliers under stated assumptions. Hopper experiment sweeps0–20% corruption. |20% is a corrupted-pair fraction in this benchmark and method, not temporal jitter or an allowance for ordinary BC. |
| [Black et al., RTC, NeurIPS 2025](https://papers.nips.cc/paper_files/paper/2025/file/300ccb2187dedd4edcc07f7e76d8e553-Paper-Conference.pdf), §3–4 | Coordinates asynchronous overlapping action chunks by conditioning on already committed actions. ## What follows, and what does not

**Inference from this evidence:** exploiting noncausal context and measuring downstream replay are defensible. Treating deterministic observation delay as automatically absorbed by every architecture is unsupported. Grounding an effect representation to the intended executor requires labelled experience or a verified transfer model. Correlated, independent and systematic errors need separate experiments.

**Not found:** any controlled study here demonstrating that±25ms is universally acceptable for60Hz continuous touch trajectories at0.03 normalized accuracy. For a locally straight path moving at normalized speed v, a timing shift δ creates position error v|δ|. Thus the allowable residual depends on speed, contact boundaries, renderer, occlusion, frame phase and metric. The0.03 target yields a geometric timing budget≈0.03/v seconds in such a segment, not a global latency rule.
